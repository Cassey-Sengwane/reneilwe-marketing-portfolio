# Reneilwe Moagi Marketing Portfolio

A Next.js portfolio website for Reneilwe Moagi.

## Included

* Professional portrait and graduation images
* Brand activation gallery and Candlelight image
* The Graduate academic campaign materials
* Tropika and Red Square academic campaign materials
* Public safe CV
* LinkedIn and Instagram details

## Run locally

```bash
npm install
npm run dev
```

## Publish

Upload the complete folder to GitHub, then import the repository into Vercel.

## Important

The two campaign assignments are academic concepts. Planned targets are not presented as achieved results. Alcohol related concepts must retain adult audience and responsible marketing context.
